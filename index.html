01 / Profile

About Me

Web Developer and IT Professional at the Schools Division Office of Camarines Norte (SDO Camarines Norte), with experience designing, developing, and maintaining web-based systems that improve organizational efficiency and digital transformation.

I specialize in full-stack web development using PostgreSQL, Express.js, React, Node.js (PERN Stack), Laravel, and Supabase for database management, authentication, backend services, and API development. My expertise includes RESTful API integration, CRUD applications, role-based access control (RBAC), UI/UX design, responsive web development, and performance optimization.

I build modern web and mobile applications that are scalable, secure, and user-centered. Recently, I have been expanding my expertise in Generative AI, integrating AI-powered technologies into applications to automate workflows, enhance productivity, and deliver smarter digital experiences.

I am a CSS NC II Certified professional and hold Google AI Certifications, reflecting my commitment to continuous learning, innovation, and developing high-quality software solutions for both government and private sector organizations.
